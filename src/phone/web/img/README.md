# Картинки страницы «Компьютер рядом»

Готовая серия — «Ночная обсерватория»: миниатюрные сцены из графита, матового стекла и меди,
коралловые световые орбиты и лунные мотивы. Все шесть WebP имеют размер 600×400 и весят 10–23 КБ каждый.
Иллюстрации созданы встроенным image_gen; точные промпты сохранены в [PROMPTS.md](PROMPTS.md).

Сюжеты серии: световая передача сертификата; замок с отметкой защищённой связи; общая орбита со звездой
для запоминания телефона; касание телефона, управляющее курсором; устройства под общей луной;
приглушённый пульт под замком для ожидания разрешения. Текст и кнопки остаются элементами страницы.

Всё, что лежит здесь с расширением `.webp`, `.png`, `.jpg` или `.svg`, при сборке попадает внутрь RadialMenu.exe
(`cmake/embed.cmake`) и отдаётся телефону как `img/<имя>`. Картинки нет - страница просто показывает шаг без неё.

Имена - только латиница, цифры, точка, дефис, подчёркивание. Всё едет внутри exe, поэтому лёгкие: webp,
до ~150 КБ, около 600x400 (на экране - до 260 точек в ширину, телефон берёт вдвое больше для чёткости).
Фон - прозрачный или тёмный (#0f0d12 - #1a1620), акцент - красно-коралловый (#e0414f - #ff7b5c).

| Файл | Где | Что показать |
|---|---|---|
| `setup-cert.webp` | Настройка, шаг «Сертификат этого ПК» | телефон с щитом/замком и сертификатом, который «ложится» в него с ноутбука |
| `setup-secure.webp` | шаг «Сертификат на месте» | закрытый замок, зелёная отметка, связь телефон - ноутбук |
| `setup-pair.webp` | шаг «Запомнить этот телефон» | телефон и ноутбук «знакомятся»: закладка, звёздочка, сердечко |
| `setup-ctl.webp` | шаг «Разрешить управление» | рука на тачпаде телефона, курсор на ноутбуке, кнопка «Разрешить» |
| `setup-done.webp` | «Всё готово» | спокойная сцена: телефон и ноутбук рядом, полумесяц (луна - знак MoonDesk) |
| `gate.webp` | вкладка, которой пока нельзя управлять | небольшой замок или приглушённый пульт, без текста |
