## Дорожная карта 1.7+ (утверждена пользователем, начинать отсюда)

Порядок по исследованию (что хотят пользователи, что сделали MusicBee, foobar2000, Plexamp, Feishin,
«Яндекс Музыка»). Пункт 1 делает пользователь на своём компьютере, облачная сессия - со 2-го.

1. Проверка на Windows 11 и правки по найденному (список - раздел «Ручная проверка»). Делает пользователь.
2. (сделано в 1.7) Форматы M4A/AAC, Opus, OGG, ALAC через Media Foundation: новый IDecoder рядом с MiniaudioDecoder, выбор по
   расширению в OpenDecoder, теги MP4 (atoms ©nam/©ART/©alb/covr/trkn) и Ogg/Opus (Vorbis Comment) в core/tags,
   IsSupportedAudio, фильтр диалога, библиотека. Без ffmpeg загрузчик сохраняет как есть (mp3=false уже есть).
3. (сделано в 1.7) SMTC (системная медиапанель): ISystemMediaTransportControls через ISystemMediaTransportControlsInterop
   (GetForWindow), название, исполнитель, обложка (поток из байтов), кнопки, позиция. Через WinRT ABI без C++/WinRT
   (проверить, что есть в заголовках mingw-w64; если нет - свои объявления интерфейсов, как с DWM-атрибутами).
   Это же даёт управление из RadialMenu.
4. (сделано в 1.7) Синхронные тексты песен: LRCLIB (/api/get?track_name=&artist_name=&album_name=&duration=, без ключа),
   кэш .lrc рядом с треком или в данных, вкладка «Текст» с подсветкой текущей строки (анимации как у текста
   трека). Разбор LRC - переносимый код с тестами. Сеть - WinHTTP в фоновом потоке. Можно плагином v2.
5. (сделано в 1.7) Локальные «Итоги» (топ исполнителей и треков, часы прослушивания, месяц и год) и «Волна» - бесконечная
   очередь из любимого и давно не слушанного с учётом времени суток. Данные: library.json (plays, lastPlayed);
   нужна история прослушиваний (отдельный файл, дописывать при «дослушан до 50%»). Логика переносимая, с тестами.
6. Окно настроек (этап 2, mockup/SETTINGS.md). Следующая сессия - отсюда.
7. Теги: редактор, обложки из Cover Art Archive, исправление по MusicBrainz.
8. Эквалайзер и кроссфейд (второй голос движка уже есть), API плагинов v3 для обработки звука.

Не делать: скины Winamp (.wsz), видео, подкасты. Визуализатор Milkdrop (projectM, LGPL) - только после
проверки лицензии; свой полноэкранный визуализатор на D2D - можно.

## Этап 1.7 (сделано)

- Форматы: `core/decoder_mf.cpp` - IMFSourceReader отдаёт float в родном формате, в формат движка переводит
  `ma_data_converter`; перемотка - `SetCurrentPosition` и отброс сэмплов до цели по метке времени. Выбор по
  расширению в `OpenDecoder` (.m4a .m4b .aac .ogg .oga .opus), `IsSupportedAudio` их принимает только в Windows.
  Теги MP4 и Ogg - в `core/tags.cpp` (Vorbis Comment и PICTURE у FLAC вынесены в общие функции). Загрузчик без
  ffmpeg просит у yt-dlp `bestaudio[ext=m4a]`.
- SMTC: `ui/smtc.*`. Интерфейсов SMTC в заголовках mingw-w64 нет - объявлены свои по метаданным SDK (сверены
  с заголовками Wine и windows-rs), IID делегатов посчитаны по правилам WinRT (алгоритм проверен на известном
  IID ButtonPressed). Позиция - `ISystemMediaTransportControls2::UpdateTimelineProperties` при смене трека,
  паузе и перемотке (дальше Windows двигает ползунок сама). Кнопки и перемотка приходят окну сообщением.
- Тексты: `core/lyrics.*` (переносимо: LRC, LRCLIB, кэш, фоновый `LyricsService` с подставной сетью в тестах),
  `ui/http.*` (WinHTTP), вкладка «Текст» - `view/lyrics_panel.cpp` и `Painter::DrawLyrics`.
- История и «Волна»: `core/history.*` (учёт, `history.jsonl`, итоги, подбор), `ui/app_stats.cpp` (страница
  «Итоги» как встроенная страница панели после страниц плагинов, меню, дописывание Волны).
- Решения:
  - Текст ищется только когда вкладка «Текст» на экране (не шлём названия треков в сеть без нужды). Порядок:
    `.lrc` рядом с треком, кэш `lyrics/<хеш>.lrc`, `/api/get`, затем `/api/search`. «Не найдено» кэшируется
    на 14 дней; нет сети - не кэшируется, повтор - со следующим треком (не на каждом кадре).
  - Встроенные в теги тексты (USLT, LYRICS, ©lyr) не читаются - YAGNI до просьбы.
  - Запись истории - когда трек сменился или плеер закрылся, если прослушано от 30 с; «полное» прослушивание -
    половина трека, но не больше 4 минут. Время суток - местное (смещение берётся на момент подсчёта).
  - «Волна» не сохраняется между запусками как режим: плейлист остаётся, дописывание - после нового запуска Волны.
  - Порядок вкладок: Очередь, Текст, страницы плагинов, Итоги (если открыты), Плагины.
- Проверено: `pm_tests` Linux 66 тестов / 1044 проверки, ASan+UBSan и TSan чисто; `pm_tests.exe` под Wine
  67 тестов (с `PM_MEDIA_DIR`: M4A AAC, M4A с обложкой, ALAC, Opus, OGG Vorbis из ffmpeg - длина, декодирование,
  перемотка); фаззинг разбора MP4/Ogg (15 000 мутаций под ASan). Под Wine в окне: M4A и Opus играют, вкладка
  «Текст» с локальным .lrc (подсветка, перенос, автопрокрутка), запись `history.jsonl`, «Итоги», запуск Волны,
  вызовы SMTC (трассировка Wine: каждый вызов попал в нужный метод vtable). Сборка mingw без предупреждений.
- Не проверено (нужна Windows): SMTC на настоящей системе - панель громкости, экран блокировки, обложка
  (у Wine заглушки для Thumbnail, ButtonPressed и ISystemMediaTransportControls2 вовсе нет), кнопки из
  панели и перемотка; живой LRCLIB (из облака сайт недоступен; формат ответа сверен с исходниками сервера);
  WinHTTP через прокси; Media Foundation в аудиопотоке на настоящей Windows (под Wine - gstreamer); OGG/Opus
  без «Расширений для веб-мультимедиа»; отрисовка вкладки «Текст» с настоящими шрифтами.

## Библиотека и плагины (сделано)

  аудиопотоке потребуют отдельных правил (без блокировок и выделения памяти).

## Решения (не пересматривать без причины)

- Рендер: D3D11 + DXGI swap chain для композиции + D2D 1.1 + DirectComposition. Если DComp недоступна -
  swap chain окна без прозрачности (акрил выключается).
- Своя рамка: `WM_NCCALCSIZE` -> 0, заголовок рисуем сами, `WS_CAPTION` оставлен ради системной тени и углов.
  Углы и тень окна системные для всех тем (этап 1); маленький радиус темы - малое скругление.
- Рост окна (плейлист, мини-режим) - мгновенный `SetWindowPos`, анимируется содержимое (решение пользователя).
- Темы, импорт и экспорт на этапе 1 - меню по правому клику (решение пользователя).
- Ядро - отдельная статическая библиотека с узким API (`core/player.h`, совместим с C++17). Для RadialMenu
  рекомендован отдельный процесс и управление через SMTC (этап 4), канал `\\.\pipe\PlayerMoon` - позже.
- JSON и проверка схемы - свои; схема `assets/theme-schema.json` - единственный источник правил.
- Дуги SVG в иконках переводятся в кривые Безье своим кодом (`view/svg_arc.*`), не `AddArc`.
- Обложка рисуется заливкой скруглённой рамки кистями (без слоёв D2D): дешевле и сама обрезается.
- Нет звукового устройства - плеер работает молча (null-бэкенд) и показывает предупреждение.
- `state.json` рядом с exe, если папка доступна на запись, иначе `%APPDATA%\PlayerMoon`. Там же
  `library.json`, `plugins/` (свои плагины) и `plugins-data/`.
- Плагины - DLL с C API в процессе плеера; выключены по умолчанию, включение с подтверждением.
- Библиотека только дописывает новые файлы в плейлист из библиотеки; убранные руками треки не возвращаются.
- Таймеры только пока нужны: 1 с во время игры в мини-режиме или свёрнутом окне, 30 с автосохранение во время
  игры, разовый 2 с после изменений. В покое - ни одного.

## С чего начать этап 2

1. Окно настроек: отдельное окно или панель поверх (решить с пользователем), вкладки по `mockup/SETTINGS.md`.
2. Смены обложки и текста: варианты в `view/player_view.cpp` (`OnTrackChanged`, `SwapLine`), отрисовка в
   `ui/painter.cpp` (`DrawCover`, `DrawLine`).
3. Визуализаторы: модель общая (`view/visualizer.*`), стили - в `Painter::DrawVisualizer` по `drawStrip` из макета.
4. `coverblur`: эффект Gaussian Blur над картинкой обложки, кэш по serial и размеру окна.

## Сборка и проверка

- Windows: `build.cmd`, тесты `build.cmd test`.
- Linux: `cmake -S . -B build-linux -G Ninja && cmake --build build-linux && ./build-linux/pm_tests`.
- Кросс-сборка: `tools/cross-build.sh`. Запуск под Wine: `wine64` с `LANG=C.UTF-8` (иначе не видны файлы
  с кириллицей в имени) и ALSA null-устройством, если в системе нет звука.
