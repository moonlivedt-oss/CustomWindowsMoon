# PlayerMoon: настройки

Полный список настроек окна «Настройки» макета (`mockup/index.html`, схема `pm-schema`) для переноса на C++.

Связанные файлы:
- `themes/<id>.json` - 5 встроенных тем с полным набором значений (`settings` + `material`);
- `theme-schema.json` - JSON Schema формата `playermoon-theme` версии 1;
- `layouts.json` и `LAYOUTS.md` - геометрия раскладок;
- `ANIMATIONS.md` - анимации, кривые, пружины.

Все эти файлы генерируются из `index.html` скриптом `tools/export-themes.js`, поэтому значения совпадают с макетом
(проверено: значения по умолчанию в `themes/*.json` равны тем, что макет выставляет в браузере при выборе пресета).
`theme.json` - старый сырой выгруз CSS-переменных, оставлен для справки; для C++ основной источник - `themes/*.json`.

## Формат файла темы

Один формат, два вида:

| Вид | Поля | Назначение |
|---|---|---|
| Встроенная (`"kind": "builtin"`) | `format`, `version`, `kind`, `id`, `name`, `settings` (все 39 ключей), `material` | Самодостаточная: всё, что нужно для отрисовки. Поставляется с плеером. |
| Пользовательская (`"kind": "user"` или поле отсутствует) | `format`, `version`, `name`, `settings` (`skin` обязателен, остальные ключи - по желанию) | Ссылка на встроенную тему (`settings.skin`) и переопределения поверх неё. Так макет экспортирует файл. |

Итоговая тема = `material` встроенной темы `settings.skin` + её `settings` + переопределения пользователя + геометрия
раскладки `settings.layout` из `layouts.json`.

`material` - значения, которые пользователь не настраивает (цвета кнопок и панелей, радиусы элементов, тени, шрифты,
размеры, базовые длительности). Цвета: `"#RRGGBBAA"` или ссылка `{ "ref": "accent", "alpha": 0.1 }`, где `ref` - один из
`accent`, `accent2`, `text`, `glow` (акцент с прозрачностью `settings.glow`), `windowSolid` (цвет фона окна без
прозрачности). Ссылки пересчитываются при каждой смене акцента, в том числе при «Акценте из обложки».

Правила чтения (как в макете): неизвестные ключи игнорируются, неверные варианты и цвета отбрасываются, числа обрезаются
по диапазону, файл больше 200 КБ не читается. Схема строже (запрещает лишние ключи), чтобы ловить ошибки в своих файлах.

## Таблица настроек

Типы: `seg` - выбор из вариантов, `range` - число в диапазоне, `color` - цвет `#rrggbb`, `toggle` - да/нет.
«Тема» - входит ли ключ в файл темы. Настройки вкладки «Звук» (кроме визуализатора) в тему не входят и хранятся
в состоянии плеера. Значения по умолчанию по темам - в следующем разделе.

## Что в Win32 сделать нельзя или трудно

Оценка по документированному API. «Win11» - Windows 11 22H2 и новее (там появился `DWMWA_SYSTEMBACKDROP_TYPE`);
проверять на конкретной сборке.

| Настройка | Проблема в Win32 | Предлагаемая замена |
|---|---|---|
| `backdrop = acrylic` | Системный материал есть только в Win11: `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE, DWMSBT_TRANSIENTWINDOW)` (Acrylic, размывает окна под собой) или `DWMSBT_MAINWINDOW` (Mica, размывает только обои). На Windows 10 документированного способа нет; недокументированный `SetWindowCompositionAttribute` с `ACCENT_ENABLE_ACRYLICBLURBEHIND` известен лагами при перетаскивании. | Win11: Acrylic. Windows 10: автоматически `solid` с тем же цветом и `winDensity` = 1, в настройках пометка «недоступно в этой версии Windows». |
| `blur` при акриле | Радиус размытия и насыщенность (`material.effect.saturate`) системного материала не настраиваются. | При `acrylic` ползунок «Размытие» скрыт или неактивен. Ползунок работает для `coverblur`: обложку размываем сами эффектом Gaussian Blur в Direct2D, результат кэшируется на трек. |
| `winDensity`, `tint`, `noise` при акриле | У системного Acrylic свой оттенок, яркость и шум, отключить их нельзя. | Свой полупрозрачный слой (`winColor` с `winDensity`, градиент оттенка, тайловая текстура зерна) поверх системного материала. Итог будет плотнее и чуть отличаться от макета, подобрать значения на глаз. |
| `radius` | Окно с системным материалом и системной тенью скругляется только по правилам DWM: `DWMWA_WINDOW_CORNER_PREFERENCE` даёт квадрат, 8 px или 4 px. Произвольный радиус для системного фона невозможен. | Для `acrylic`: углы системные (около 8 px), ползунок работает только для мини-режима и внутренних элементов либо неактивен. Для остальных фонов: окно без системного фона (`WS_EX_NOREDIRECTIONBITMAP` + DirectComposition), содержимое обрезается своим скруглённым клипом с любым радиусом. |
| `shadow` | Своя тень (`soft`, `deep`, `glow`) рисуется за пределами окна, значит окну нужно прозрачное поле вокруг. С системным материалом такое поле тоже окажется акриловым. | Для `acrylic`: системная тень DWM, выбор тени неактивен. Для остальных фонов: прозрачное поле 48-80 px вокруг окна, своя тень эффектом Shadow, клики по полю пропускаются (`WM_NCHITTEST` -> `HTTRANSPARENT`). |
| `playlist = side` и мини-режим (изменение размера окна) | Анимированный размер окна. Вариант «окно сразу большего размера с прозрачной частью» не работает с системным материалом: акрил ляжет и на прозрачную часть. | Сплошные фоны: окно максимального размера, анимируется клип содержимого через DirectComposition, без SetWindowPos по кадрам. Акрил: SetWindowPos по кадрам анимации (около 20 вызовов за 320 мс, синхронно с DwmFlush) или мгновенный размер и анимация только содержимого. Решение принять в плане этапа 1. |
| `playlist = sheet` при акриле | В макете под шторкой размывается содержимое окна (backdrop-filter 24 px). DirectComposition размывать не умеет. | Отрисовать содержимое под шторкой в битмап, размыть эффектом Gaussian Blur Direct2D один раз при открытии (содержимое под шторкой почти статично), или без размытия и с непрозрачностью панели 0.9. |
| `coverShape = vinyl` | В Direct2D нет повторяющегося радиального градиента для бороздок. | Набор концентрических окружностей толщиной 1 px через 5 px (около 18 штук для обложки 176 px) или битмап, нарисованный один раз. |
| `accentFromCover`, `vizColor = cover`, оттенок фона | В макете цвета берутся из хеша названия. У настоящей обложки цвета нужно вычислять. | Есть обложка в тегах: уменьшить до 32x32, взять 2-3 доминирующих цвета (гистограмма по оттенку или k-средних); нет обложки: тот же хеш-алгоритм, что в макете. |
| `titleWeight` | Произвольная насыщенность 300-800 требует переменного шрифта: ось `wght` через `IDWriteFontFace5` / `DWRITE_FONT_AXIS_VALUE` (Windows 10 2004 и новее). Segoe UI Variable есть только в Win11. | Win11: переменный Segoe UI Variable с осью `wght`. Иначе - ближайшее статическое начертание (Segoe UI: 300, 400, 600, 700). |
| `coverFx = blur`, `textFx = blur`, `vizGlow`, `glow` | Анимированное размытие и свечение - эффекты Direct2D, их нельзя отдать DirectComposition, кадры считает приложение. | Допустимо: только во время анимации (300-400 мс) или пока играет визуализатор. Свечение статичных иконок рисовать один раз в битмап. |
| `coverFx = flip` | Нужна 3D-трансформация с перспективой. | Есть в DirectComposition: `IDCompositionRotateTransform3D` + `IDCompositionMatrixTransform3D` для перспективы 900 px. |
| `coverFx = wipe`, `textFx = wipe` | Анимация клипа. | `IDCompositionRectangleClip` с анимируемыми сторонами. Без кадров приложения. |
| Пружина (`motion`, `stiffness`, `damping`) | Анимации DirectComposition задаются кусками кубических полиномов, физической пружины в них нет. | Свой таймлайн с формулой пружины (ANIMATIONS.md) или аппроксимация пружины кубическими сегментами `IDCompositionAnimation::AddCubic`, построенная один раз при смене параметров. |
| `rate` с сохранением высоты тона | В miniaudio нет time-stretch: изменение скорости меняет и высоту тона. | Отдельная библиотека на этапе 4 (лицензия MIT/BSD/zlib; SoundTouch - LGPL, Rubber Band - GPL, не подходят). |
| `desk`, `deskColor` | Фон страницы макета, в плеере нет «страницы». | Не переносить. В файле темы ключи остаются ради совместимости с макетом, плеер их игнорирует. |
| `motion = none`, флажок «Меньше движения» | - | Системная настройка: `SystemParametersInfo(SPI_GETCLIENTAREAANIMATION)`, обновлять по `WM_SETTINGCHANGE`. При выключенных анимациях Windows - сокращённый режим, как `motion = none`. |
| Шрифт | Segoe UI Variable нельзя класть в репозиторий (лицензия), его нет в Windows 10. | Системный шрифт по имени; свои шрифты - через `IDWriteFontSetBuilder` из папки шрифтов приложения, имя - отдельным ключом темы (добавить в C++ версии). |

Остальное переносится напрямую: цвета, градиенты, маски прозрачности бегущей строки (`ID2D1Layer` с opacity mask),
визуализатор, точки, сегменты, тени элементов (эффект Shadow в Direct2D), трансформации и прозрачность слоёв.
