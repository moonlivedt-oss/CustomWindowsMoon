# PlayerMoon: анимации интерфейса

Справочник для переноса макета `mockup/index.html` на C++20 + Direct2D/DirectComposition.
Значения берутся из `themes/<id>.json` (`settings` - выбранные варианты, пружина и множитель; `material.duration`
и `material.easing` - базовые длительности и кривые), формат описан в `theme-schema.json`, настройки - в
`SETTINGS.md`, раскладки - в `LAYOUTS.md`. Длительности ниже даны для множителя «Длительность анимаций» = 1;
итоговая длительность = базовая * `speed`. Ключи в таблицах записаны как в CSS макета (`duration.fast`); в
`themes/*.json` те же ключи лежат в `material.duration.fast`.

## Как собирается движение

1. Материал задаёт базовые длительности (`duration.*`) и кривые (`easing.*`).
2. Характер движения (`characters`) задаёт пружину (жёсткость, затухание), ease-out и множитель `speed`.
3. Пользователь может поверх менять множитель, жёсткость и затухание, а для каждого места - вид анимации
   (обложка, текст, кнопки, пуск/пауза).
4. «Без анимаций» или системная настройка Windows «Эффекты анимации» выкл. (`SPI_GETCLIENTAREAANIMATION`)
   включают сокращённый режим (см. в конце).

## Характеры движения

| Ключ | Название | Жёсткость k | Затухание c | Время пружины, мс | Перелёт | ease-out | Множитель |
|---|---|---|---|---|---|---|---|
| `soft` | Мягко | 420 | 26 | 428 | 7.6% | cubic-bezier(0.22, 1, 0.36, 1) | 1 |
| `bouncy` | Пружина | 300 | 14 | 684 | 25.0% | cubic-bezier(0.16, 1, 0.3, 1) | 1 |
| `calm` | Спокойно | 300 | 30 | 284 | 0.4% (после успокоения) | cubic-bezier(0.25, 0.8, 0.25, 1) | 1 |
| `snappy` | Резко | 700 | 46 | 188 | 0.4% (после успокоения) | cubic-bezier(0.2, 0.9, 0.1, 1) | 0.7 |
| `slow` | Медленно | 160 | 22 | 392 | 0.4% (после успокоения) | cubic-bezier(0.33, 1, 0.68, 1) | 1.6 |
| `none` | Без анимаций | - | - | 80 | - | - | 0.35 к длительностям |

Пресеты по умолчанию: Стекло - `soft`, Иней - `snappy`, Неон - `bouncy`, Закат - `slow`, Минимал - `calm`.

Пружина: масса 1, x(t) = 1 - e^(-z*w*t) * (cos(wd*t) + (z*w/wd) * sin(wd*t)), где w = sqrt(k),
z = c / (2*w), wd = w * sqrt(1 - z^2); для z >= 1 - формулы критического и передемпфированного случая
(они есть в `springCurve` в макете). Время пружины - последний момент, когда |1 - x(t)| > 0.005.
Перелёт - максимум x(t) минус 1. В CSS пружина задана выборкой `linear(...)` из 41 точки; в C++ лучше
считать формулу на каждом кадре. Все переходы «масштаб/ручка/точка» идут за время пружины
(`duration.spring` * множитель), а не за фиксированные мс.

### Эталоны для unit-теста пружины

Посчитано той же функцией `springCurve`, что в макете (время до множителя `speed`); пик найден с шагом 0.5 мс, поэтому
он точнее, чем выборка из 41 точки в CSS (там перелёт `bouncy` выходит 24.8%). Тест в C++ должен совпасть в
пределах 0.002 по x(t) и 4 мс по времени (шаг поиска в макете 4 мс).

| Характер | z = c / (2 sqrt k) | Время успокоения, мс | Пик x, момент пика | x(100 мс) | x(200 мс) |
|---|---|---|---|---|---|
| `soft` | 0.634 | 428 | 1.0759 в 199 мс | 0.7801 | 1.0759 |
| `bouncy` | 0.404 | 684 | 1.2496 в 199 мс | 0.7873 | 1.2494 |
| `calm` | 0.866 | 284 | 1.0043 в 363 мс | 0.5610 | 0.9229 |
| `snappy` | 0.869 | 188 | 1.0040 в 240 мс | 0.8037 | 0.9998 |
| `slow` | 0.870 | 392 | 1.0040 в 503 мс | 0.3871 | 0.7798 |

Время успокоения - последний момент, когда |1 - x(t)| > 0.005, плюс шаг 4 мс. У `calm`, `snappy`, `slow` пик меньше
порога 0.5%, поэтому он приходится уже после времени успокоения, и в выборку для CSS (0..Ts) не попадает.

## Смена обложки (настройка «Обложка», ключ `coverFx`)

dir = 1 при переходе вперёд, -1 назад. Т = `duration.cover`. Уходящая обложка удаляется после своей анимации.

| Вариант | Уходящая обложка | Новая обложка | Время | Кривая |
|---|---|---|---|---|
| `fade` Затухание | прозрачность 1 -> 0 | прозрачность 0 -> 1 | уход 0.8Т, приход Т | in / out |
| `slide` Сдвиг | сдвиг 0 -> -100%*dir ширины, клип рамкой | сдвиг 100%*dir -> 0 | Т и Т | out / out |
| `zoom` Наплыв | прозрачность -> 0, сдвиг -24*dir px, масштаб -> 0.9 | прозрачность 0 -> 1, сдвиг 24*dir -> 0, масштаб 1.06 -> 1 | 0.8Т / Т | in / out |
| `rotate` Поворот | поворот -> -40*dir град, масштаб -> 0.75, прозрачность -> 0 | поворот 40*dir -> 0, масштаб 0.75 -> 1, прозрачность 0 -> 1 | 0.8Т / Т | in / пружина |
| `flip` Переворот | 3D: перспектива 900 px, rotateY 0 -> -90*dir | rotateY 90*dir -> 0, начинается после ухода | 0.5Т / 0.5Т с задержкой 0.5Т | in / out |
| `wipe` Шторка | стоит на месте | клип-прямоугольник раскрывается от края (справа при dir = 1) | Т / Т | out |
| `blur` Размытие | прозрачность -> 0, размытие 0 -> 14 px, масштаб -> 1.05 | прозрачность 0 -> 1, размытие 14 -> 0 px, масштаб 0.96 -> 1 | 0.8Т / Т | in / out |

В C++: `flip` - IDCompositionMatrixTransform3D (или Rotate3D + перспектива), `wipe` - клип визуала,
`blur` - эффект GaussianBlur на слое обложки.

## Смена текста (настройка «Текст», ключ `textFx`)

Название, исполнитель, альбом уходят и приходят по очереди с задержкой 30 мс на строку.
Уход: 0.45 * `duration.text`, кривая in. Приход: `duration.text`, кривая out.

| Вариант | Уход | Приход |
|---|---|---|
| `rise` Подъём | прозрачность -> 0, сдвиг Y -> -6 px | прозрачность 0 -> 1, сдвиг Y 10 -> 0 px |
| `slide` Вбок | прозрачность -> 0, сдвиг X -> -16*dir px | прозрачность 0 -> 1, сдвиг X 16*dir -> 0 |
| `fade` Затухание | прозрачность -> 0 | прозрачность 0 -> 1 |
| `blur` Размытие | прозрачность -> 0, размытие 0 -> 6 px | прозрачность 0 -> 1, размытие 6 -> 0 px |
| `wipe` Шторка | клип снизу: видимая часть 100% -> 0 | клип сверху 100% -> 0 и сдвиг Y 35% -> 0 |

## Кнопки (настройка «Реакция», ключ `btnFx`)

| Вариант | Наведение | Нажатие | Время и кривая |
|---|---|---|---|
| `spring` Пружина | масштаб 1.08, фон `color.btn-hover` | масштаб 0.9, фон `color.btn-press` | масштаб: пружина; нажатие `press`; фон `fast` out |
| `press` Нажатие | только фон | масштаб 0.9 | то же |
| `lift` Подъём | сдвиг Y -3 px, тень 0 6 14 rgba(0,0,0,0.22) | масштаб 0.96 | то же |
| `glow` Свечение | масштаб 1.04, цвет иконки акцент, кольцо 1 px и свечение 16 px акцента | масштаб 0.94 | то же, свечение `base` out |
| `none` Нет | только фон | нет | фон `fast` |

Общее для всех: при отпускании масштаб возвращается пружиной (с перелётом у `soft` и `bouncy`).
Включённые повтор/перемешивание/плейлист: цвет -> акцент (`fast`), индикатор под иконкой масштаб 0 -> 1
(пружина); форма индикатора из материала (`size.dot-w/h`, `radius.dot`), у Неона вместо него свечение
`shadow.btn-active`. Режим повтора «один»: цифра 1 прозрачность 0 -> 1, масштаб 0.4 -> 1 (пружина).

| A | (8.5,5) (14,8.5) (14,15.5) (8.5,19) | (6.5,5) (10,5) (10,19) (6.5,19) |

Дополнительно, только при нажатии пользователем:

| Вариант | Что добавляется | Время | Кривая |
|---|---|---|---|

## Визуализатор (вкладка «Звук»)

Данные: 16-96 полос (`vizBars`). Цель каждой полосы - шум + два синуса + бит 128 ударов в минуту,
умноженные на громкость движка (см. «Плавный старт и пауза»). Рост к цели экспонентой со скоростью
`vizAttack` в секунду, падение линейно `vizFall` высоты в секунду. На паузе полосы падают со скоростью
fall * (0.6 + v), при max < 0.001 цикл кадров останавливается.

Раскладка «Сцена» рисует кольцо вокруг обложки (начало лучей зависит от формы обложки: круг R+12,
скруглённая 1.25R+6, квадрат 1.42R+6), остальные раскладки - полосу.

| Вид | Полоса | Кольцо |
|---|---|---|
| `bars` Столбцы | скруглённые столбцы от низа | лучи наружу |
| `mirror` Зеркало | столбцы вверх и вниз от средней линии | лучи от средней окружности в обе стороны |
| `lines` Линии | линии 2 px | тонкие лучи 1.3 px |
| `wave` Волна | сглаженная кривая через вершины (квадратичные Безье через середины), заливка 22% | замкнутая сглаженная кривая, заливка 18% |
| `dots` Точки | точка на высоте значения и тусклая точка у основания | точка на конце луча и тусклая у начала |
| `led` Сегменты | ячейки 3 px через 2 px, тусклые 10% | ячейки 4 px через 3 px вдоль луча |
| `off` Нет | не рисуется | не рисуется |

Цвет (`vizColor`): `accent` - градиент по индексу от акцента ко второму акценту; `cover` - от светлого к
основному цвету обложки (обновляется после смены трека); `mono` - цвет текста. Свечение `vizGlow` -
тень-размытие того же цвета (в D2D - Shadow effect под слоем визуализатора).

## Воспроизведение (вкладка «Звук», в тему не входит)

| Настройка | Поведение | Что видно |
|---|---|---|
| Скорость 0.5-2x | позиция и время визуализатора идут быстрее/медленнее | значок «1.25x» между временем и длительностью, появляется с масштабом 0.8 -> 1 (пружина) |
| Кроссфейд 0-12 с | за N секунд до конца стартует следующий трек; обложка и фон перетекают все N секунд затуханием; не работает при повторе одного трека, «Остановить после текущего» и на последнем треке без повтора | штрихованная зона в конце прогресса, статус «Переход» |
| Плавный старт и пауза 0-1500 мс | громкость движка линейно идёт 0 -> 1 или 1 -> 0; иконка морфится сразу, позиция идёт, пока громкость не дошла до 0 | полосы визуализатора растут и опадают вместе с громкостью |
| Остановить после текущего | в конце трека переход на следующий без запуска; флажок сам выключается | переключатель гаснет |

## Правило «ноль кадров в покое»

- Один общий цикл кадров (в макете `requestAnimationFrame`, в C++ - тик на vsync).
- Следующий кадр запрашивается, только если кто-то занят: движок играет или громкость ещё не дошла до 0,
  полосы визуализатора не опустились, бегущая строка не доехала до шва, пластинка крутится.
- Наведение, нажатие, переходы панелей и смены обложки в макете - CSS-переходы и Web Animations; в C++ это
  анимации DirectComposition (IDCompositionAnimation), которые не требуют кадров от приложения.
- Индикатор «Цикл кадров» на странице макета показывает состояние и счёт кадров.

## Сокращённые анимации

Включаются характером «Без анимаций», системной настройкой или флажком «Меньше движения» на странице:

- реакция кнопок принудительно `none`, пружина заменена мгновенной, время пружины 80 мс;
- все длительности умножаются на 0.35, изменение размера окна мгновенное, лесенки нет;
- смена обложки и текста - только затухание, кроссфейд - тоже без растянутой анимации обложки;
- бегущей строки нет: длинное название обрезается многоточием;
- пластинка не вращается, анимация эквалайзера в плейлисте выключена, свечение полос визуализатора 0;
- сам визуализатор работает: это содержимое, а не украшение.
