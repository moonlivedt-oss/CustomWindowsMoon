# PlayerMoon в RadialMenu

Исходники PlayerMoon перенесены из локальной копии проекта автора в `player/`. Это обычный каталог репозитория RadialMenu, не подмодуль и не загрузка с GitHub во время сборки. Старый репозиторий для работы и сборки не нужен. Miniaudio остаётся в `player/third_party/miniaudio` со своей исходной лицензией. Макет, темы, документация плагинов, исходные тесты и ресурсы тоже сохранены.

## Как открыть

- Студия → Стол → карточка «Сейчас играет» → «Открыть PlayerMoon».
- Палитра команд: найти PlayerMoon.
- Правый клик по нижней медиапанели → «Открыть PlayerMoon».
- В карточке на странице «Стол» можно добавить PlayerMoon в правое кольцо. Настройка сохраняется обычным механизмом RadialMenu и поддерживает отмену.
- Для ручного пункта кольца: `path = {player}`. Этот путь разрешается от папки RadialMenu и работает после переноса всей папки приложения.

Плеер запускается отдельным процессом только по запросу. Запуск RadialMenu сам по себе не включает аудиодвижок. Закрытие RadialMenu не останавливает отдельно открытый PlayerMoon.

В PlayerMoon можно открыть MP3, FLAC, WAV, M4A/AAC/ALAC, OGG/Opus; некоторые форматы требуют соответствующего декодера Windows. Библиотека, очередь, мини-режим, плагины и собственные темы плеера сохранены. Подробности — в `player/README.md`.

## Связь с нижней панелью

PlayerMoon публикует название, исполнителя, обложку, статус и позицию через Windows SMTC. RadialMenu читает их своим существующим `media::Watcher`; кнопки пуск/пауза, следующий/предыдущий, перемотка и управление с телефона используют тот же системный путь, что для других плееров. Название источника показывается как PlayerMoon. Клик по обложке возвращает окно плеера на передний план.

Для корректного WinRT на Windows добавлены `RoInitialize` и стабильный AppUserModelID `MoonDesk.PlayerMoon`. Исправлено повторное открытие невидимого окна: скрытое окно теперь показывается даже если оно не было свёрнуто.

Тема плеера пока выбирается в самом PlayerMoon; тема RadialMenu не перезаписывает его собственное оформление.

## Сборка и поставка

Обычный `build.cmd` собирает обе программы одним инструментарием MSYS2 UCRT64. C++20 нужен только PlayerMoon; RadialMenu остаётся на C++17. На диске:

```
RadialMenu.exe
apps/PlayerMoon/PlayerMoon.exe
apps/PlayerMoon/assets/
apps/PlayerMoon/plugins/history/
apps/PlayerMoon/plugins/downloader/
```

Флаг CMake `RADIAL_PLAYER=OFF` позволяет собрать меню без плеера. Для обычной поставки флаг включён по умолчанию. Нужно переносить всю папку `apps/PlayerMoon`, а не один EXE. Windows CI также собирает плеер, запускает его тесты и прикладывает папку к артефакту.

Сборка не заменяет уже установленный EXE, если SHA-256 не изменился: можно пересобирать меню при запущенном неизменившемся плеере. При обновлении самого плеера его следует закрыть, чтобы Windows освободила EXE.

Состояние, библиотека, история и кэш текстов сохраняются рядом с EXE плеера, если папка доступна для записи; иначе — в `%APPDATA%/PlayerMoon`. Обновление копирует только программу, assets и файлы штатных плагинов, не удаляя пользовательские state.json, library.json, history.jsonl и lyrics. Установленные сторонние плагины также не удаляются.

Загрузчик музыки остаётся необязательным плагином, выключенным до включения пользователем. Внешние yt-dlp и ffmpeg не скачиваются и не устанавливаются автоматически. Для самого плеера они не нужны.

## Проверка

- `build.cmd test`: тесты RadialMenu и 67 тестов PlayerMoon (1044 проверки в исходном наборе).
- `cmake --build build-check --target pm_tests`, затем `build-check/player/pm_tests.exe`: интегрированная сборка тестов.
- `tests/player_bridge_check.cpp`: ручная проверка на Windows через настоящий `media::Watcher`. Без аргументов только читает данные. `--exercise` дополнительно проверяет воспроизведение, паузу, перемотку, следующий и предыдущий трек; использовать с двумя отдельными тестовыми WAV с тишиной, а не с пользовательской очередью. Проверка адресуется только источнику `MoonDesk.PlayerMoon`.

Команда сборки ручной проверки из корня проекта:

```
g++ -std=c++17 -O2 -DNOMINMAX -DUNICODE -D_UNICODE -D_WIN32_WINNT=0x0A00 -I src tests/player_bridge_check.cpp src/desk/media.cpp src/core/text.cpp -static -lole32 -lshell32 -lpropsys -luuid -lshlwapi -o build-check/player_bridge_check.exe
```

Папка Downloads/PlayerMoon и старый репозиторий не изменялись. Удалять удалённый репозиторий разумно после того, как импортированный код сохранён и в удалённом репозитории RadialMenu: локальный коммит сам по себе на GitHub не отправляется.
