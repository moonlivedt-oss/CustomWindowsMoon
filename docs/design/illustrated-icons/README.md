# Объёмные тематические значки RadialMenu

156 отдельных PNG: по 12 предметов для всех 13 тем из `src/core/themes.cpp`. Это отдельные генерации изображений, не перекрашенные SVG. Генератор — встроенный imagegen; точные промпты всех 13 листов сохранены в [prompts.json](prompts.json). Оригинальные листы `<theme>-sheet.png` оставлены здесь для последующей переработки. Общий лист — [preview.png](preview.png).

## Наборы

Багровое поле, Закат, Лунная ночь, Catppuccin, Tokyo Night, Dracula, Rosé Pine, Nord, Gruvbox, One Dark, Лес, Из обоев, Своя палитра.

Для «Из обоев» сделаны нейтральное серебро и прозрачное стекло; для «Своей палитры» — серебро и мягкий перламутр. Эти два набора не перекрашивают свои пиксели по цвету обоев, а сочетаются с разными акцентами. В остальных наборах цвета и материалы заданы отдельно.

В каждом наборе: Проекты, Код, Учёба, Игры, Музыка, Программы, Папки, Загрузки, Интернет, Терминал, Карьера/соревнования, Инструменты. Это основные назначения секторов, а не замена всех специализированных сетевых и служебных иконок. Прежние значки тоже остаются доступными.

## Как выбирать

Студия → Кольца → нужный сектор → «3 Значок» → «Подобрать значок».

- «Подходящие» предлагает образы по названию и пути сектора. Если назначение не распознано, учитываются подписи вложенных пунктов; затем предлагаются универсальные папки, программы и проекты. Точные совпадения ставятся первыми.
- Поиск понимает русские названия, английские имена и несколько слов: `книга`, `музыка`, `study book`. Регистр и ё/е не мешают. При поиске рекомендации не скрывают найденные совпадения.
- Категории: разработка, учёба, игры, музыка, файлы, сеть, система, карьера. «Все» показывает все категории выбранного набора.
- Оформление: «Объёмные», «Все» (включая прежние), «Прежние».
- Меню темы позволяет примерить любой набор. В режиме «Автоматически» подборщик показывает набор текущей темы RadialMenu.
- Подпись и подсказка объясняют предмет. Нажатие или перетаскивание к квадрату применяет значок; работают прежние сохранение и отмена.

Выбранный значок сохраняется явным относительным путём `icons/illustrated/<theme>/<name>.png`. Последующая смена темы оформления сама по себе не заменяет уже назначенные значки. «Автоматически» относится к фильтру подборщика, а не к перезаписи колец пользователя.

Все рекомендации и поиск выполняются локально. Содержимое папок для подбора не сканируется, данные в сеть не уходят. Список значков читается при первом открытии подборщика в сеансе студии; после добавления новых файлов нужно закрыть и открыть студию заново.

## Файлы и проверка

Рабочие ресурсы: `RadialMenu/icons/illustrated/<theme>/*.png`, RGBA 256×256, прозрачные поля. Размер объектов нормализован при нарезке. Импорт отбрасывает мелкие несвязанные фрагменты соседних ячеек, сохраняя значимые отдельные части вроде кубика над контроллером.

Повторная нарезка: `python tools/import_illustrated_icons.py crimson art/illustrated-icons/crimson-sheet.png` из папки RadialMenu. Полная проверка всех наборов: `python tools/import_illustrated_icons.py --check`.

Семантические тесты: `tests/test_icon_catalog.cpp`, собрать с `g++ -std=c++17 -Wall -Wextra -Werror -I src tests/test_icon_catalog.cpp -o build-check/test_icon_catalog.exe`, затем запустить. Проверяются кириллица, ё/е, многословный поиск, сортировка рекомендаций, точное попадание в проект и универсальные рекомендации.

Проверочный снимок: `RadialMenu.exe --studio-snap 0 2 build-check/icon-picker.png 2500`. Снимок изолирован от рабочего окна и не меняет конфигурацию.

Предыдущий исполняемый файл перед установкой новой сборки сохранён в `backups/before-illustrated-picker/`. В этой работе новые значки добавлялись отдельными файлами; текущие назначения секторов не заменялись автоматически.
