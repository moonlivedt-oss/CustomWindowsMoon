# Пейзажи для карточек тем

Картинки для раздела «Темы» в Radial Studio. Все 11 сделаны одной серией: одна композиция и один стиль,
меняется только время суток и палитра. Объединяет серию маленькая деталь: в небе над горами еле заметная
дуга из семи звёздочек, похожая на полукольцо меню.

Формат: 16:9, без текста. Готовые файлы клади в `RadialMenu\art\themes\` с именами из заголовков.
Я пережму их в WebP и подключу к карточкам. Для темы «Из обоев» картинка не нужна: там показываются
твои настоящие обои.

**Общий хвост: дописывай в конец каждого промпта**

```
Calm painterly digital landscape for a theme preview card, wide 16:9. Layered mountain and hill silhouettes fading into atmospheric haze, a still lake in the lower third that mirrors the sky, soft gradients, gentle bloom on light sources, smooth and slightly stylized like a cozy desktop wallpaper, very little detail in the lower left corner (small color dots will be placed there). High in the sky, a faint arc of seven small soft stars curving like a half-ring, subtle and easy to miss. The palette below is strict: every color in the image comes from it.
Avoid: text, letters, logos, watermark, signature, people, animals, buildings in the foreground, user interface, frames, borders, harsh contrast, noise, oversaturated neon
```
