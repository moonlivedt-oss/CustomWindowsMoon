## Наборы

В `RadialMenu/icons/themes/` лежат одинаковые имена PNG и SVG:

- `crimson`: багровый акцент на графите, установлен по умолчанию;
- `aurora`: мята на тёмном бирюзовом;
- `dusk`: лаванда на фиолетовом;
- `sand`: тёмные символы на светлом песочном фоне.

Темы охватывают разработку, обучение, игры, музыку, карьеру, соревнования, документы, веб и базы данных, а также общую навигацию.

Из папки RadialMenu: `python tools/apply_icon_theme.py aurora`, затем перезапустить программу. Скрипт меняет только 25 основных PNG; собственные цвета проектов сохраняются. Конфигурация колец не изменяется. Можно также указать отдельному сектору `icon = icons/themes/dusk/music.png`.

## Исходники и восстановление

### Значки папок в Проводнике

Установлены для 17 папок проектов через `desktop.ini` и стандартный Windows Shell API. ICO лежит в `branding/folder.ico`. Для библиотеки `image` значок хранится снаружи библиотеки, в `RadialMenu/art/identity/logos/image.ico`; учёт картинок библиотеки не меняется. Пути относительные, поэтому сохраняются при переносе всей папки `components`.

Повторная установка после генерации графики: `python tools/install_folder_icons.py` из RadialMenu. Для обновления открытого списка нажать F5. Возврат прежних значков: `python tools/install_folder_icons.py --restore`. Исходные `desktop.ini` и атрибуты сохранены в `backups/explorer-folder-icons/`. Атрибут ReadOnly на папке — стандартный сигнал Проводнику читать настройки оформления; он не запрещает запись файлов.

Прошлые версии RadialMenu и Les до доработки сохранены в `backups/identity-before-refinement/`. У Les образ выбран по содержимому проекта фестиваля «Волна», а не по названию папки. Сами макеты фестиваля не менялись.

`python tools/build_identity.py` воспроизводит наборы и устанавливает ресурсы. Нужны Python и Pillow. SVG и PNG строятся из одной геометрии, PNG сглажены с уменьшением в четыре раза. Размер PNG — 256×256, прозрачные углы; ICO содержит 16, 24, 32, 48, 64, 128 и 256 px.

Оригиналы заменённых файлов сохранены в `RadialMenu/backups/identity-originals/` с путями от `components`. Генератор не перезаписывает эти резервные копии при повторном запуске. Для возврата скопировать нужный файл из резервной папки по соответствующему пути проекта. Переключатель палитр отдельно сохраняет исходное состояние в `backups/before-icon-theme/`.

`python tools/build_identity.py --check` проверяет XML всех SVG, декодирование, размер и альфа-канал PNG. В HTML есть образцы 16/24/32/48 px для проверки читаемости. Изменения чужого кода, найденные в рабочих деревьях, не затрагивались.
