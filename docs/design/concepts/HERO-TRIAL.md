# Пробный первый экран

Новая иллюстрация создана встроенным imagegen по двум референсам: текущий `docs/img/hero.webp` задаёт стиль, `pocket-observatory.png` — идею глубины выбранного сектора. Использованы багровое стекло, крупные формы, второй уровень кольца и спокойное поле под заголовок. Бронзовая механика первого концепта исключена.

Полноразмерный PNG: `hero-observatory.png`. WebP для страницы: `../../../docs/img/hero-observatory.webp` (около 64 КБ).

Пробная страница: `../../../docs/hero-trial.html`. Внизу справа кнопки «Исходный / Новый» переключают фон без перезагрузки. Основной `docs/index.html` и исходная иллюстрация сохранены без изменений. В светлой теме фото скрывается, как в основной странице. После изменений исходной страницы пробную можно обновить командой `python tools/build_hero_trial.py`.
