# Radial Menu

Круговое меню папок для Windows. Зажми **Alt** и доведи курсор до **левого или правого края** экрана: из края раскроется полукольцо. У каждого края свой набор секторов.

## Управление

| действие | что делает |
|---|---|
| навести на сектор | раскрывает второе кольцо (содержимое папки или свой список) |
| отпустить Alt над сектором, клик или Enter | открыть |
| Shift + открыть | открыть в VS Code |
| Ctrl + открыть | терминал в этой папке |
| Ctrl + Shift + открыть | показать в Проводнике |
| ПКМ по папке, колесо вверх | зайти внутрь (сверху появится путь) |
| ПКМ мимо, колесо вниз, Backspace, клик по центру | назад |
| колесо, стрелки | листать страницы, если пунктов много |
| просто печатать | поиск по всем кольцам на два уровня вглубь; раскладка не важна: «ghjtrns» найдёт «Проекты» |
| Esc | очистить поиск, назад, закрыть |

**Перетаскивание файлов.** Тащишь файл, у края экрана зажимаешь Alt, бросаешь на сектор. На папку файл переносится или копируется (как в Проводнике, Shift и Ctrl выбирают сами). На программу или ярлык файл открывается в ней, на корзину удаляется. Если подержать файл над папкой, меню зайдёт в неё. Подсказка внизу показывает, что произойдёт.

**Оформление.** Под кольцом стекло: обои просвечивают с размытием. Акцент по умолчанию берётся из обоев (`accent = auto`). Тихие звуки при открытии и наведении, громкость настраивается.

## Горячие углы

У каждого угла три действия:

- **Задержать.** Курсор в углу около 250 мс: из угла растёт свечение с дугой ожидания, потом выполняется действие. Отвёл раньше, и ничего не будет.
- **Толкнуть дважды.** Два быстрых толчка курсором в угол (каждый короче задержки) выполняют второе действие.
- **Колесо.** Курсор в углу, крутишь колесо: яркость (внешний монитор через DDC/CI, экран ноутбука через WMI), общая громкость или треки (вверх следующий, вниз предыдущий). Уровень рисуется дугой и числом прямо в углу.

Действия: показать рабочий стол, все окна, Пуск, выключить экран, заблокировать, снимок области, пауза, следующий трек, без звука, любое сочетание клавиш (записывается в студии) или программа и файл. По умолчанию левый нижний угол показывает стол, а колесо там меняет яркость. Правый нижний открывает все окна, колесо в нём меняет громкость.

Углы не срабатывают с зажатым Alt (это кольцо), с нажатой кнопкой мыши и поверх игр на весь экран. Развёрнутое окно игрой не считается, даже если при скрытой панели задач оно закрывает весь экран.

## Сейчас играет

Доведи курсор до нижнего края экрана (не в угол): снизу выедет карточка с тем, что играет. Обложка, источник, название, исполнитель, полоса времени и кнопки. Цвет кнопки и полосы берётся из обложки, фон карточки - она же, размытая. Трек приходит из системных медиа-сеансов Windows, поэтому подходит любой плеер, в том числе музыка в браузере.

| действие | что делает |
|---|---|
| кнопки | назад, пауза, вперёд; «назад» дальше 3 секунд от начала перематывает в начало трека, кнопки, которые плеер сам выключил (нет очереди), гаснут |
| колесо над карточкой | громкость самого плеера (не всей системы) |
| клик по полосе | перемотать |
| клик по обложке или названию | открыть плеер |
| кнопка со строками | текст песни: карточка раскрывается вверх |
| клик по строке текста | перемотать к ней |
| переключатель сверху | если играют несколько программ, выбрать, какую показывать |
| ПКМ | текст песни, выключить панель |

Текст берётся с [lrclib.net](https://lrclib.net) (бесплатно, без ключей): синхронизированный подсвечивает текущую строку, обычный листается колесом. Для поиска туда уходят название и исполнитель трека. Из заголовков видео вроде «Control (Halsey) - Demon Slayer [AMV]» поиск сам вытаскивает название и исполнителя.

При смене трека снизу на 3 секунды выглядывает маленькая карточка; навёл на неё, и раскроется большая. Отключается в студии.

## Окна: прозрачность и поверх всех

Наведи курсор на верхнюю полосу любого окна (заголовок, вкладки):

| действие | что делает |
|---|---|
| Alt + колесо | прозрачность окна, шаг 5%, от 20% до 100% |
| Alt + средняя кнопка | закрепить поверх всех окон или открепить |

Рядом с окном всплывает подсказка с уровнем. Закреплённое окно получает тонкую рамку цвета темы. Действие для угла «Окно поверх всех» закрепляет активное окно. При выходе программы (или через пункт трея «Вернуть окнам прозрачность и закрепление») все окна возвращаются как были. Окна, запущенные от администратора, Windows менять не даёт, подсказка так и скажет. Выключается в студии, раздел «Стол».

## Кольцо окон

**Alt + ` (клавиша Ё)** открывает вокруг курсора кольцо открытых окон: то же, что Alt+Tab на текущем рабочем столе, по программам в порядке последнего использования. У программы с несколькими окнами второе кольцо раскрывается с их заголовками. В середине кольца живая миниатюра наведённого окна, внизу его полный заголовок.

| действие | что делает |
|---|---|
| отпустить Alt над сектором / клик | вывести окно вперёд (свёрнутое разворачивается) |
| средняя кнопка | закрыть окно, оно сразу пропадает из кольца |
| набор текста | поиск по названиям программ и заголовкам окон |
| Alt + ` ещё раз, Esc | закрыть кольцо |

То же кольцо можно повесить на горячий угол (действие «Кольцо окон»). Выключается в студии, раздел «Система».

## Кольцо в диалогах «Открыть» и «Сохранить»

Если впереди стандартный диалог выбора файла (в любой программе), кольцо не открывает Проводник, а работает с диалогом:

- **папка** - диалог переходит в неё, имя файла в поле остаётся прежним;
- **документ** - диалог переходит в его папку и подставляет имя, остаётся нажать Enter;
- **программы и ярлыки** (.exe, .lnk, .url, .bat) запускаются как обычно, Shift и Ctrl тоже работают как обычно.

Подсказка снизу пишет «Перейти сюда в диалоге». Старые диалоги «Обзор папок» (дерево без поля имени) не поддерживаются; мод Windhawk Modernize Folder Picker Dialog заменяет их обычным диалогом, и кольцо начинает работать и там.

## Стол и система

- **Двойной клик по пустому столу** открывает целое кольцо вокруг курсора: секторы левого и правого края вместе, первый сверху, дальше по часовой.
- **Заряд.** Когда заряда меньше 15% (настраивается), у нижнего края тихо дышит свечение цвета темы; подключил зарядку - по краю пробегает светлая волна.
- **Снимок области.** После Win+Shift+S справа снизу выезжает карточка с превью: «Сохранить» кладёт PNG в «Снимки экрана», «Текст» распознаёт снимок встроенным OCR Windows и кладёт текст в буфер. Клик по превью открывает снимок.
- **Ночной режим** (по умолчанию с 23 до 7): стекло карточек темнее, свечения спокойнее, звуки вдвое тише.
- **Курсор**: цвет заливки (акцент, серебро, сталь, свой) и размер. Курсоры перекрашиваются на время работы программы, в реестр ничего не пишется.
- **Тема везде** (первая карточка раздела «Система»): одна кнопка применяет тему ко всему, что стоит: моды Windhawk одним .reg (Проводник, центр уведомлений, Параметры, поиск) и Пуск Start11. Проводник при этом перезапускается.
- **Меню Пуск** (Stardock Start11): фон из размытого куска обоев под плотной вуалью темы, подложка меню - графит с каплей акцента, кнопка Пуск перекрашена из «Triangle Two» (серебро и сталь, открытое меню - акцент, картинка в %APPDATA%\MoonDesk\start-button.png). Меню и кнопку Start11 рисует внутри Проводника, поэтому после применения Проводник перезапускается.
- **Параметры** (мод Windows 11 Settings Styler) и **поиск Windows** (мод Windows 11 Start Menu Styler, тема TintedGlass): графитовое стекло с каплей акцента.
- **Значки папок** (мод Windhawk Resource Redirect): копия текущей темы значков, где сиреневые папки стали графитовыми, а рисунки на них - цвета акцента. Тема собирается в %APPDATA%\MoonDesk\icons.
- **Центр уведомлений** (мод Notification Center Styler): тема TintedGlass с цветами темы.
- **Проводник** (мод Windows 11 File Explorer Styler): своя тема без встроенных - вкладки и панель команд в графитовом стекле с каплей акцента, тонкая акцентная кромка у адресной строки, подсказок и меню «...»; Mica только на рамке, чтобы список файлов оставался сплошным тёмным. Для проверки: `RadialMenu.exe --explorer-reg` (а также `--notify-reg`, `--settings-reg`, `--search-reg`, `--all-reg`) пишет .reg по текущей теме в %APPDATA%\MoonDesk, `--start-apply` оформляет Пуск.

Настройки модов Windhawk лежат в системной части реестра, поэтому студия готовит .reg-файл: Windows спросит разрешение, затем мод нужно выключить и включить в Windhawk.

Тема **«Багровое поле»**: графит грозового неба, багровый акцент, сталь и серебро - под обои с красными цветами.

## Красота и игровой режим

- **Живая рамка окна.** При переключении рамка нового окна вспыхивает светлым акцентом и оседает в цвет темы, у прежнего плавно гаснет до стали. Работает для любых программ через DWM, без внедрения в процессы.
- **Заголовки под тему.** Полоса заголовка у всех окон графитовая, текст светлый, у неактивных окон приглушён. Окна, которые рисуют заголовок сами (браузер, VS Code, новый Блокнот), меняют только рамку.
- **Кольцо.** Раскрывается пружиной, секторы второго кольца проявляются волной от середины, страницы перелистываются поворотом в сторону листания, наведённый сектор выдвигается наружу, а запущенный пункт уходит волной от сектора, пока меню гаснет (клики в это время проходят насквозь).
- **Движение.** Одна настройка скорости для всех анимаций программы: спокойно, обычно, живо.
- **Экран блокировки** («Применить» в студии): обои или своя картинка подгоняются под экран и красятся под тему: тени уходят в графит, цвета, далёкие от акцента, притихают, края темнеют, сверху вуаль под часы, у нижнего края световой шов цвета акцента, как у колец. Картинка ставится через WinRT, прав администратора не нужно (`%APPDATA%\MoonDesk\lockscreen-theme.jpg`).
- **Ввод пароля.** Под аватаром и полем пароля картинка мягко затемнена, чтобы они читались. «Чёткий фон вместо размытого» убирает матовое стекло Windows с экрана входа (политика `DisableAcrylicBackgroundOnLogon` в HKLM, поэтому через .reg с подтверждением). «Аватар в стиле колец» рисует картинку для круга над полем: графит, кольцо секторов с одним багровым «наведённым» сектором, в середине полумесяц или своя картинка (`avatar_source`). Ставить аватар сама Windows разрешает только через Параметры: студия кладёт путь в буфер и открывает «Ваши данные», остаётся «Обзор файлов», Ctrl + V, Enter. Само поле и шрифты рисует LogonUI на защищённом столе, их не трогаем.
- **Переход блокировки.** При блокировке за экраном блокировки заранее встаёт копия его картинки (размытая или чёткая, как у экрана входа). После входа - «портал» (около 2 с): портал раскрывается оттуда, где курсор. Сначала на стекле проступает узор, вокруг курсора по одному, по часовой, встают секторы кольца, последним с вспышкой - багровый «наведённый»; потом фронт идёт к краям экрана. С узором стекло рассыпается по ячейкам: каждая сжимается к своей середине и гаснет, ячейки на фронте горят кромкой цвета акцента. Соты возле курсора приподнимаются, пока зажигается кольцо, а перед фронтом бежит волна приподнятых: грани, обращённые к курсору, ловят свет, противоположные и швы под ними уходят в тень. Узоры: «Соты» и «Осколки» (витраж с трещинами, `lock_pattern = hex | shards | none`); без узора - круглый вырез с тенью и бегущей по кромке искрой. Кольцо идёт впереди фронта и поворачивается, с фронта срываются искры, звучит тихий подъём с колокольчиками (если звуки включены). Кадр считается за 9 мс, узор - один раз при блокировке за 50 мс. Можно выбрать простое растворение (`lock_anim = fade`). Блокировка из горячего угла проигрывает портал назад - он схлопывается в угол. Посмотреть - «Показать» в студии.

**Сотовое стекло** (`hex_glass`) - общий стиль для всего, что связано с порталом:

- **Углы.** Пока курсор ждёт в углу, из угла веером загораются соты, сота у фронта чуть больше - встаёт на место; при срабатывании все вспыхивают светлым.
- **Кольцо.** По секторам идут тонкие грани сот, каждая сота чуть своей яркости; сота под курсором приподнята (светлее, с яркой кромкой), соседние подсвечены.
- **Зарядка.** Вместо светлой волны по нижнему краю бежит волна сот: у фронта они встают выше и горят ярче, позади гаснущий след.
- **Игровой режим.** При включении и выключении от середины нижнего края по периметру экрана в обе стороны бегут загорающиеся соты (включение - акцентом, выключение - сталью), внизу на пару секунд плашка «Игровой режим: игра» или «Игровой режим выключен». Поверх эксклюзивного полноэкранного режима не показывается.

Портал работает не только после разблокировки:

- **При входе после включения** (`boot_portal`): если программа запустилась вместе со входом в Windows (Проводник стартовал меньше полутора минут назад), картинка проступает поверх стола и раскрывается порталом.
- **После сна и выключения экрана** (`wake_portal`): действие угла «Выключить экран» сначала схлопывает портал в угол, потом гасит экран; перед сном картинка встаёт заранее. Когда экран включится (или после пробуждения придёт ввод), стол открывается порталом. Если при этом сработала блокировка, портал ждёт входа.

**Игровой режим** выключает всю красоту, пока запущена игра: анимации колец и карточек мгновенные, без стекла, свечений заряда, панели «Сейчас играет» и рамок окон, перехват мыши для углов и окон снимается. Заодно (каждое по отдельности) выключаются анимации и прозрачность Windows и ставится на паузу Wallpaper Engine; после выхода из игры всё возвращается как было. Если программа упадёт посреди игры, при следующем запуске она вернёт настройки сама (`%APPDATA%\MoonDesk\gamemode.ini`).

**Память перед игрой (Boost).** Логика скриптов `D:\Desktop\components\Boost` перенесена внутрь, конфиг общий - `boost.config.json` (белый список, защищённые, что чистить), так что скрипты и меню Boost работают и дальше.

- При запуске игры (если по `minFreePercent` памяти мало и закрывать есть что, от 150 МБ) справа снизу выезжает карточка «Освободить ~1.2 ГБ перед игрой?» со списком программ (имена из описания файла). Без клика ничего не закрывается; карточка не отнимает фокус у игры.
- «Освободить»: программы закрываются мягко (WM_CLOSE, как крестик), через `gracefulTimeoutMs` добиваются; при `trimWorkingSet` сжимаются рабочие наборы, при `purgeStandby` чистится кэш памяти. Итог - «Освобождено 1.1 ГБ». Закрытое пишется в `boost.session.json` в формате Boost (`GameBoost -Restore` тоже сможет вернуть).
- Пока идёт игра: таймер 0.5 мс (`timerResolution`), пониженный приоритет процессов из `deprioritize`, Game DVR выключен (`disableGameDvr`).
- После игры: приоритеты и таймер возвращаются, память чистится ещё раз, карточка предлагает вернуть закрытые программы (открываются свёрнутыми).
- Очистке кэша нужны права администратора: в студии «Очистка кэша без запросов - Настроить» один раз создаёт задачу планировщика `MoonDesk\RadialMenuPurge` (Windows спросит разрешение), дальше она запускается без запросов (`RadialMenu.exe --purge`).
- Вручную: пункт трея «Освободить память...», действие угла «Освободить память», кнопка в студии.

Игрой считается программа из папок по маскам `games` (по умолчанию все игры Steam, Epic, EA, Wuthering Waves, NFS14.exe; `games_skip` - исключения вроде Wallpaper Engine) или всё, что идёт в эксклюзивном полноэкранном режиме. Вручную режим включается и выключается в меню значка в трее; выключенный посреди игры не включится снова, пока она не закроется.

## Автозапуск и память

- «Запускать вместе с Windows» (трей или студия, раздел «Поведение») создаёт задачу планировщика `MoonDesk\RadialMenuStart` «при входе»: она стартует раньше программ из `Run`, с обычным приоритетом, и портал после включения успевает показаться. Прав администратора не нужно. Если планировщик недоступен, используется `HKCU\...\Run`; старая запись из `Run` при запуске переносится в задачу сама, а если exe переехал, путь обновляется.
- Выключение автозапуска в Диспетчере задач учитывается: переключатель покажет «выключено».
- Память в простое: после закрытия кольца, студии, панели, снимка или карточки через несколько секунд кучи сжимаются и рабочий набор отдаётся системе (`core/mem`). Пока кольцо открыто, обрезка ждёт. В покое около 2-4 МБ рабочего набора.

## Radial Studio

Двойной клик по значку в трее (или `RadialMenu.exe --editor`) открывает студию:

- **Кольца**: секторы левого и правого края, порядок меняется перетаскиванием, папки и файлы можно бросать прямо в окно. Вкладки «Основное», «Второе кольцо», «Значок». Если путь пропал (папку переместили), сверху появится плашка с кнопкой «Найти».
- **Темы**: 12 тем с пейзажами (палитры из cpp-docs-panel, «Лунная ночь», «Из обоев», «Своя палитра»). Тема красит и кольца, и саму студию. Сверху витрина выбранной темы с палитрой и кодами цветов; при наведении на карточку витрина и вся студия примеряют её.
- **Поведение**: где открывать, стекло, размер, звук, терминал, автозапуск.
- **Система**: значки папок, центр уведомлений, фон Пуска, курсор, заряд, ночной режим, двойной клик по столу, карточка снимка.
- **Стол**: три действия на каждый угол (задержка, двойной толчок, колесо), запись сочетаний клавиш, панель «Сейчас играет» и карточка при смене трека.
- **Красота**: скорость движения, рамки и заголовки окон, игровой режим (что выключать, маски игр, текущее состояние), экран блокировки и просмотр перехода.
- **Клавиши**: шпаргалка по управлению меню.

Управление в студии:

| действие | что делает |
|---|---|
| ПКМ по сектору | меню: переименовать, выше, ниже, на другой край, дублировать, удалить |
| двойной клик по названию, F2 | переименовать прямо в списке |
| тянуть сектор | поменять порядок; на кнопку другого края - перенести туда; на середину простого сектора - сделать пунктом |
| тянуть пункт второго кольца в список | сделать отдельным сектором |
| стрелки, Alt+стрелки | выбрать сектор, сдвинуть сектор |
| Delete, Ctrl+D | удалить, дублировать |
| Ctrl+Z, Ctrl+Y | отменить, вернуть |
| наведение на тему | примерить её на студию |

После удаления и переносов внизу на 5 секунд всплывает уведомление с кнопкой «Отменить». В списке помечаются секторы с пропавшим путём, без пути и с «раскрытием» не папки. Перед сохранением студия делает резервную копию `radial.cfg` в `backups\` (до 10 штук, не чаще раза в 10 минут), вернуть её можно из «Журнала».

Всё сохраняется само в `radial.cfg`, «Отменить» внизу (или Ctrl+Z) откатывает последнее изменение, «Журнал» показывает историю. «Показать меню» открывает кольцо у края для проверки.

## Картинки

Промпты для генерации лежат в `art\PROMPTS.md`. Готовые листы клади в `art\` и запускай:

```
python tools\import_art.py
build.cmd
```

Скрипт разрежет листы на значки, уберёт зелёный фон и положит всё в `icons\`. `build.cmd` нужен, только если поменялась иконка приложения. Значки секторов, которых ещё нет (`downloads.png`, `cpp.png` и т.д.), пока подменяются системными.

## Сборка

```
build.cmd
```

Нужны MSYS2 ucrt64 (`g++`, `cmake`, `ninja`) в `D:\msys64`. Готовый `RadialMenu.exe` появляется в корне проекта рядом с `radial.cfg`.

`radial.cfg` у каждого свой и в репозиторий не входит: при первом запуске он копируется из `radial.example.cfg`
(кольца с Документами, Загрузками, Музыкой и другими общими папками), дальше всё настраивается в студии.

Проверочная сборка, не останавливая работающую копию: `cmake -S . -B build-check -G Ninja -DRADIAL_OUT_DIR=build-check`,
потом `cmake --build build-check`.

## Устройство

```
src/
  app/      main.cpp - трей, опрос Alt + край экрана; autostart - запуск с Windows;
            devcli - служебные режимы запуска (--ocr, --dlg, --lock-apply, --purge и другие)
  core/     config - radial.cfg; themes - 12 тем; text, files - строки и пути;
            launch - VS Code, терминал, фокус; perf - замеры; fx - скорость анимаций и игровой режим;
            winlist - окна для кольца окон; filedlg - переход в диалогах «Открыть/Сохранить»
            (для проверки: RadialMenu.exe --dlg путь)
  gfx/      hex - геометрия сот; icons - картинки и значки оболочки; color, draw - цвета, размытие, геометрия;
            accent - цвет из обоев; sound - звуки
  desk/     corners - горячие углы; media - что играет (WinRT без заголовков, свой поток);
            volume - громкость системы и плеера; brightness - яркость (DDC/CI, WMI); lyrics - lrclib.net;
            widget, widget_draw - панель «Сейчас играет» у нижнего края (логика и рисование); winfx - прозрачность и «поверх всех» для окон;
            frame - рамки и заголовки окон; gamemode - игровой режим (для проверки: --game-test);
            lockscreen - картинка блокировки и аватар (для проверки: --lock-apply, --avatar),
            lock_reveal - переход после входа, lock_portal - узор стекла и портал;
            hexwave - волна сот игрового режима; boost, boostcard - Boost и его карточка
  menu/     menu.h - класс меню; menu.cpp - окно и перехватчики; menu_rings - второе кольцо и поиск;
            menu_input - мышь и клавиши; menu_drop - перетаскивание файлов; menu_draw - рисование
  studio/   studio.h - вход; studio.cpp - окно и кадр; studio_data - отмена, сохранение, копии, проверки;
            studio_rings, studio_tabs - кольца и вкладки сектора; studio_themes - витрина и галерея тем;
            studio_pages, studio_system, studio_style, studio_overlays - остальные разделы и всплывающие окна
  ui/       элементы студии на GDI+ (кнопки, переключатели, поля, подсказки)
  res/      значок, манифест, ресурсы
```

Новые `.cpp` подхватываются сборкой сами (CMake собирает всё из `src`).

### Замеры

`set RADIAL_PROFILE=1` перед запуском: при выходе рядом с exe появится `profile.log` со временем основных операций
(кадр меню, открытие, снимок под стекло, кадр студии по разделам).

`set RADIAL_SNAP=1`: каждый кадр панели «Сейчас играет» сохраняется в `media_snap.png` рядом с exe.
